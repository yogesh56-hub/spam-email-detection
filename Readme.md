# Spam Email Detection Using Machine Learning

## Project Overview
This project classifies text messages as spam or legitimate using Machine Learning and Natural Language Processing techniques.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Logistic Regression
- Scikit-learn
- Streamlit

## How It Works
1. The user enters a text message.
2. TF-IDF converts the text into numerical features.
3. Logistic Regression predicts whether the message is spam or legitimate.
4. Streamlit displays the prediction.

## How to Run the Project

1. Clone this repository.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Run the Streamlit application:
   `streamlit run app.py`
